# README assets

- `endurance-banner.png`: original image generated with OpenAI's built-in image generation tool, inspired by the modular ring structure of the Endurance spacecraft from *Interstellar*. A new cinematic composition, rather than a film still or poster. See [generation prompt](endurance-banner.prompt.txt).
- `endurance-cat.png`: original endurance mascot generated with OpenAI image generation. Prompt direction: a cute cream-white kitten holding a lavender laptop, a paw emblem, soft pastel colors, no lettering, and a transparent background.
- `endurance-architecture.svg`: repository-specific architecture illustration, maintained as editable SVG. Based on the workspace, client, server, session core, and voice implementation in this repository.
- `tech/*.svg`: Devicon v2.17.0, downloaded from https://github.com/devicons/devicon/tree/v2.17.0/icons. The MIT license is preserved in `tech/DEVICON-LICENSE`. Technology marks belong to their respective owners; their use identifies this project's stack and does not imply endorsement.
- README technology badges: rendered by Shields.io with the flat style, a black background, and white Simple Icons logos. See https://shields.io/badges/static-badge and https://simpleicons.org/.

- `endurance-mark.svg`: original editable vector mark representing a twelve-module orbital ring. Used for ENDURANCE product marks, favicons, and desktop icons.
- Web social share images use the ENDURANCE banner described above. OpenCode Zen provider artwork identifies the external service and is preserved.
